# Security Policy — Patchbysk

## Scope

This policy covers this repository only. It does not cover third-party apps that are patched with this tool.

## Authorized use

This tool touches APK files. Use it only on APKs you own or are explicitly authorized to test. Do not use it to bypass protections, access other people's accounts or data, or break platform rules.

## Reporting a vulnerability

Open a GitHub Issue in this repository describing the issue **without** including exploit details or a working exploit.

## Out of scope

- Vulnerabilities in third-party apps processed by this tool — report those to the app's own vendor.
